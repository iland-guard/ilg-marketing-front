# Sentra AI Landing (React)

React + Vite + Tailwind recreation of the Sentra AI / Maya marketing landing page.

## Run

```bash
cd sentra-web
npm install
npm run dev
```

## Routes

- `/` — landing page
- `/payments` — placeholder for future checkout / BE
- `/privacy-policy` — privacy stub
- `/accessibility` — accessibility stub

## Notes

- Assets live in `public/assets` (copied from the WordPress backup / live site).
- Contact form is UI-only for now; wire to your backend later.
- Design tokens follow the original Elementor palette (`#050a14`, `#139bff`, Heebo/Inter).
